# 🍽️ What We Eat

**What We Eat** es una aplicación web que utiliza Inteligencia Artificial para ayudarte a crear recetas a partir de los ingredientes que tienes disponibles.

La idea es simple: introduces los ingredientes que tienes en casa y la IA genera una receta personalizada.

Ejemplo:

> **"Solo tengo:"**
>
> - Pollo
> - Arroz
> - Cebolla

La aplicación genera una receta utilizando esos ingredientes y permite adaptarla según tus necesidades.

---

## ✨ Funcionalidades

- 👤 Registro e inicio de sesión con JWT.
- 📝 Crear, guardar y gestionar recetas.
- 🤖 Generar recetas mediante Inteligencia Artificial.
- ✍️ Mejorar instrucciones de preparación.
- 🔥 Calcular calorías y valores nutricionales.
- 🍴 Sugerir acompañamientos.
- 💪 Crear planes de alimentación según objetivos:
  - Pérdida de peso.
  - Ganancia muscular.
  - Preparación para competición.
- 🔎 Buscar y filtrar recetas.
